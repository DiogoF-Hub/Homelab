# Root crontab on wazuh-home (Wazuh manager + indexer + dashboard).
#
# Install with: sudo crontab -e (as root) and paste the line(s) below.
# Verify with:  sudo crontab -l
#
# Nightly: /root/wazuh/main.sh (apt update / upgrade / autoremove, reboot only if
# needed). Same script pattern and same cron line on every host, only
# the path and the time differ. See ./main.sh for the full flow.
#
# Nightly order across the hosts, each run well clear of the one before:
#   03:30 wazuh-home   /root/wazuh/main.sh   first: if it reboots, the
#                                            manager is back before the
#                                            other hosts' events arrive
#   04:15 Pi-hole VM   /root/pihole/main.sh  done before the Vault VM
#                                            needs its DNS + Squid
#   05:00 edge VPS     /root/vps/main.sh
#   05:35 Vault VM     Vaultwarden/root_crontab.txt
#
# Format: minute hour day-of-month month day-of-week command
30 3 * * * /bin/bash -lc '/root/wazuh/main.sh' > /dev/null 2>&1
